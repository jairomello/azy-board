# Comandos Azy Board

Os arquivos desta pasta são comandos semânticos. Clientes que suportam slash commands podem copiá-los para sua pasta de comandos; os demais podem usar os títulos como prompts.

| Comando | Efeito | Leitura ou mutação |
|---|---|---|
| `/azyboard-status` | Resume projeto, sprint, board e trabalho relevante | Leitura |
| `/azyboard-plan` | Estrutura o trabalho no nível correto | Pode criar após confirmação |
| `/azyboard-start` | Seleciona e reivindica trabalho | Mutação |
| `/azyboard-update` | Registra progresso, estado, checklist ou log | Mutação |
| `/azyboard-complete` | Valida e conclui o trabalho | Mutação |
| `/azyboard-review` | Revisa estado, evidências e bloqueios | Leitura |
