# Agentes e Integrações

Agentes de IA são colaboradores autenticados que consultam e atualizam os mesmos projetos usados pelas pessoas, respeitando as permissões do proprietário da API Key.

## Escolher uma integração

O Azy Board oferece caminhos complementares:

| Caminho | Uso principal |
|---|---|
| MCP | Disponibilizar ações estruturadas a clientes de agentes. |
| API REST | Integrar scripts e serviços diretamente. |
| Shadow Markdown | Ler e editar o Board como documento. |
| WebSocket | Receber mudanças do projeto em tempo real. |
