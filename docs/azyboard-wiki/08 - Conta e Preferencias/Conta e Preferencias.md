# Conta e Preferências

A área de conta reúne a identificação do usuário, suas preferências de experiência e as credenciais destinadas a agentes de IA.

## Acessar a conta

Selecione o avatar no cabeçalho e abra **Configurações da conta**. A página apresenta o perfil, os controles de preferência e as API Keys do usuário autenticado.

## Perfil e sessão

- [[08 - Conta e Preferencias/Acessar e Consultar a Conta|Acessar e consultar a conta]]
  
  Consulte nome, e-mail e avatar, retorne aos projetos ou encerre a sessão pelo menu do perfil.

## Preferências

- [[08 - Conta e Preferencias/Configurar Tema e Idioma|Configurar tema e idioma]]
  
  Alterne entre os modos claro e escuro, escolha o idioma e entenda como essas preferências são preservadas.

## API Keys

- [[08 - Conta e Preferencias/Gerenciar API Keys|Gerenciar API Keys]]
  
  Crie credenciais para agentes, copie o segredo exibido uma única vez, acompanhe seu uso e revogue acessos.
