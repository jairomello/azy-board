# Azy Board

O Azy Board é uma plataforma de gestão de projetos para equipes formadas por pessoas e agentes de IA. Este manual explica a aplicação de forma funcional, desde o acesso e a criação de projetos até a operação do Board, a gestão dos itens de trabalho e as integrações com agentes.

> [!info] Escopo do manual
> A documentação apresenta a visão funcional completa do produto. Cada guia explica o comportamento esperado da funcionalidade e inclui uma seção recolhível sobre seu funcionamento técnico.

## Estrutura central do trabalho

```text
Projeto
└── Módulo
    └── Épico
        └── História
            └── Task ou Bug
                └── Subtask
```

Essa hierarquia organiza tanto a visão estratégica quanto a execução diária. O Board apresenta os itens executáveis, enquanto a visualização em árvore permite observar toda a estrutura do projeto.
