# Estrutura do Trabalho

O Azy Board utiliza uma hierarquia única para conectar o planejamento estratégico ao trabalho executável.

```text
Projeto > Módulo > Épico > História > Task ou Bug > Subtask
```

## Guias

### Hierarquia

- [[03 - Estrutura do Trabalho/Hierarquia dos Itens|Hierarquia dos itens]]
  - Papel de cada nível.
  - Relações pai-filho permitidas.
  - Breadcrumb e contexto do item.
  - Itens órfãos.

### Leaf Rule

- [[03 - Estrutura do Trabalho/Leaf Rule e Itens Agregadores|Leaf Rule e itens agregadores]]
  - Diferença entre item folha e item agregador.
  - Participação de histórias, tasks, bugs e subtasks no Board.
  - Efeito de criar um primeiro filho.

### Consolidação

- [[03 - Estrutura do Trabalho/Pontos e Progresso|Pontos e progresso]]
  - Pontos de itens folha.
  - Soma de pontos nos ancestrais.
  - Progresso calculado a partir dos descendentes.
