# Glossário

| Termo | Significado |
|---|---|
| Agente de IA | Cliente automatizado que consulta ou altera o projeto por API ou MCP. |
| Azy Agent | Assistente conversacional interno do Azy Board, habilitado pelo Root do tenant. |
| Ancestry path | Caminho de ancestrais de um item, utilizado para identificar seu contexto e montar breadcrumbs. |
| API Key | Credencial criada por uma pessoa para autenticar um agente de IA. |
| Board | Área visual de acompanhamento do trabalho, composta por swimlanes, colunas e cards. |
| Breadcrumb | Caminho exibido em um card para indicar os itens aos quais ele pertence. |
| Bug | Item utilizado para representar um defeito ou comportamento incorreto. |
| Card | Representação visual de um item dentro do Board. |
| Centro de custo | Classificação financeira opcional associada a um item de trabalho. |
| Coluna | Etapa configurável do fluxo Kanban, associada a um status base. |
| Dashboard | Área gerencial do projeto com oito blocos de indicadores, como progresso, WIP, bloqueados e burnup. |
| Épico | Agrupamento de grande escopo vinculado a um módulo e usado como swimlane no Board. |
| Grupo global | Nível de privilégio da conta no tenant: `TEAM_MEMBER`, `MANAGER`, `ADMIN` ou `ROOT`. |
| História | Necessidade funcional descrita por uma narrativa ágil e vinculada a um épico. |
| Item folha | Item que não possui filhos e pode representar trabalho diretamente executável. |
| Leaf Rule | Regra que determina como itens folha e itens agregadores participam do Kanban. |
| MCP | Model Context Protocol, protocolo usado por agentes para descobrir e executar ferramentas. |
| Modo do board | Formato do projeto: `HIERARCHICAL` (módulos, épicos e histórias) ou `SIMPLE` (história fixa e fluxo único). |
| Módulo | Agrupamento funcional de alto nível dentro de um projeto. |
| Pontos | Estimativa numérica do esforço de um item. |
| Projeto | Unidade principal que reúne estrutura, pessoas, Board e configurações. |
| Projeto oculto | Projeto marcado para não aparecer nas listagens, visível apenas com a preferência da sessão ativada. |
| Projeto restrito | Projeto acessável somente a membros e ao gerente geral, mesmo para Admins e Root. |
| Shadow Markdown | Representação textual determinística do Board para consumo e atualização por agentes. |
| Sprint | Período de planejamento que agrupa itens com um objetivo temporal comum. |
| Squad | Grupo de membros dentro de um projeto. |
| Subtask | Task ou bug criado abaixo de outro item executável. |
| Swimlane | Faixa horizontal do Board que agrupa cards relacionados a um épico. |
| Tag | Marcador colorido usado para classificar e filtrar itens. |
| Task | Item operacional que representa trabalho a ser executado. |
| Tema claro (preset) | Variação visual do tema claro: Petróleo, Oceano, Esmeralda, Grafite ou Clássico. |
| Tenant | Organização isolada à qual usuários, projetos e dados pertencem. |
| Tree View | Visualização em árvore de toda a hierarquia do projeto. |
| Versão | Entrega planejada à qual itens podem ser associados. |
| WebSocket | Canal de comunicação utilizado para propagar atualizações em tempo real. |
