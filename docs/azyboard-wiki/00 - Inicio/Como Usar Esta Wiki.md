# Como Usar Esta Wiki

Esta pasta pode ser aberta diretamente como um cofre do Obsidian. A página [[Home]] funciona como índice principal.

## Formas de navegação

- Use a `Home` para entrar em um módulo.
- Use os links relacionados no final de cada guia para continuar o fluxo.
- Use a busca do Obsidian para localizar uma tela, ação ou conceito.
- Use o painel de backlinks para descobrir quais funcionalidades dependem de uma página.

## Organização do conteúdo

Cada pasta numerada representa um módulo funcional. Dentro do módulo, as páginas partem dos conceitos gerais para os guias específicos.

Os guias não são escritos como histórias de requisito. Eles apresentam a funcionalidade como um manual: explicam a tela, as ações disponíveis, as regras e o resultado esperado.

## Bloco técnico

As páginas funcionais podem terminar com a seção recolhível **Como funciona tecnicamente**. Ela é complementar e pode ser ignorada por quem deseja apenas utilizar a aplicação.

## Convenções visuais

> [!info] Informação
> Contexto útil para compreender uma funcionalidade.

> [!tip] Dica
> Uma forma mais eficiente de realizar uma ação.

> [!warning] Atenção
> Uma ação com impacto relevante ou que exige confirmação.

> [!danger] Ação permanente
> Uma ação que remove dados e não pode ser desfeita.

## Termos em inglês

Termos consolidados no produto, como Board, Kanban, sprint, task, bug, subtask, tag, API Key, MCP e WebSocket, são mantidos em inglês. Os demais conteúdos são escritos em português do Brasil.
